# CRISPR-GEM
Machine learning model that predicts optimal target genes for CRISPR gene editing approaches. 

Please download all files above then load the GUI by running the "GUI3_1.py" script. Make sure to have git lfc installed. The resulting gene lists and the DNN data file can be uploaded to a google drive to run the model in google colab. Detailed instructions are given in the "GEM Tutorialv1.pdf" file.
